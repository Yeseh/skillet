## What to build

Add `skillet build [name]` subcommand. `.skill` source files compile to `SKILL.md` output.

### Compilation transforms (applied to markdown body)

| Source | Output | Error condition |
|--------|--------|-----------------|
| `` `ref::./path` `` | `` `./path` `` (backticks kept) | Error if path missing relative to skill dir |
| `` `cmd::git bisect` `` | `` `git bisect` `` (backticks kept) | Warning if not on PATH, build continues |
| `` `skill::name` `` | `` `name` `` (backticks kept) | Error if skill dir not in workspace |
| `` `var::name` `` | `value` (no backticks) | Error if not declared in [vars] |
| `` `env::name` `` | `default` (no backticks) | Error if not declared in [env] |
| `{{> fragment-name }}` on its own line | fragment content verbatim | Error if fragment file not found |

Fragment files live at `<fragments_dir>/{name}.fragment.skill` — plain markdown, no frontmatter, no nesting.

### Output
- Write `SKILL.md` to `<skills_dir>/<name>/SKILL.md`
- Frontmatter passed through unchanged
- Error if frontmatter `name` field ≠ skill directory name

### Lockfile
Write/update `skillet.lock` at workspace root after a successful build:

```toml
# Auto-generated by skillet build. Do not edit. Run `skillet check` to verify freshness.

[meta]
skillet_version = "0.1.0"
built_at = "2026-05-18T14:30:00Z"
tokenizer = "cl100k_base"

[skills.diagnose]
source_hash = "sha256:abc123"
compiled_hash = "sha256:def456"
fragments_used = ["check-adrs"]
```

Use sha256 of file bytes (hex-encoded) for hashes. Skip refs subsection for now.

## Code conventions (already enforced)
- `missing_docs = "warn"` active — all public items need `///` + `//!` module header
- `#![allow(missing_docs)]` on `main.rs` and test files
- `#[cfg(test)] mod tests` with AAA comments collocated in source modules
- Integration tests in `tests/` call binary via subprocess
- `bail!` messages: lowercase, no trailing punctuation
- `#[non_exhaustive]` on new public structs
